# 8. Glosario

- **Challenge:** dato fresco enviado para probar identidad.
- **Response:** resultado criptográfico calculado sobre el challenge.
- **Nonce:** valor que debe usarse una sola vez.
- **Replay:** reutilización maliciosa de un intercambio válido anterior.
- **SHA-256:** función hash con salida de 256 bits.
- **HMAC:** código de autenticación basado en hash y clave secreta.
- **MAC:** etiqueta que protege integridad y autenticidad, no confidencialidad.
- **Clave simétrica:** secreto compartido por dispositivo y verificador.
- **Comparación en tiempo constante:** comparación que no termina en el primer
  byte diferente.
- **Elemento seguro:** circuito dedicado al almacenamiento y uso protegido de
  secretos criptográficos.
- **ATECC608:** familia de elementos seguros con funciones criptográficas; este
  proyecto solo toma inspiración conceptual y no la emula completamente.
- **RISC-V:** arquitectura abierta del núcleo usado por la GD32VW553.
